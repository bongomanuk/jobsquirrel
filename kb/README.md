# Knowledge base (required for targeted documents)

This folder holds the **raw personal documents** the agents are allowed to draw
facts from, and the **GraphRAG index** built from them. It is how you keep CVs,
letters and answers truthful: the agent grounds every claim in this corpus.

It is **required** for document generation: the targeted CVs and letters are written from the cited context pack this produces. (Grounding can fall back to `config/cv.json` only if you truly cannot run GraphRAG.)

**Feed it everything — the more, the better.** The richer the corpus, the sharper
and more honest every application: retrieval can surface the exact achievement,
metric and technology a given ad asks for, with a citation. Do not stop at a CV —
add a master CV, every old/role-specific CV, a brag document with numbers,
project/design notes, talks, reviews, awards, and a LinkedIn export. Keep every
fact traceable to a real experience. **Any format works** — PDF, DOCX, DOC/ODT,
HTML, Markdown, email, CSV/JSON; the ingest step converts it to text for you.
No corpus evidence, no claim.

## Layout

```
kb/
  sources/                 # YOUR documents (text). Put anything here:
                           #   old CVs, a master CV, project notes, product docs,
                           #   a brag/achievements doc, your LinkedIn export, ...
  graphrag/
    settings.example.yaml  # GraphRAG config template -> copy to settings.yaml
    .env.example           # secrets/model config -> copy to .env
    prompts/               # GraphRAG prompts (override to tune extraction)
    input/                 # your sources copied/symlinked here, ready to index
    output/  cache/  logs/ # generated by indexing (git-ignored)
```

## Build it

```bash
# 1. Put your documents in kb/sources/ (any format), then ingest them to text
python3 tools/kb_ingest.py --sources kb/sources --out kb/graphrag/input

# 2. Configure
cp kb/graphrag/settings.example.yaml kb/graphrag/settings.yaml
cp kb/graphrag/.env.example          kb/graphrag/.env      # then edit .env

# 3. Ensure the embeddings backend is up (local llama.cpp by default)
bash tools/embeddings_vulkan.sh

# 4. Install GraphRAG and build the index (one-off; can take a while)
pip install graphrag          # or use an existing .venv-graphrag
python3 -m graphrag index --root kb/graphrag

# 5. Verify and query
python3 tools/kb_graphrag.py --check
python3 tools/kb_graphrag.py --text "example role, key technologies, metrics"
```

See [docs/KNOWLEDGE-BASE.md](../docs/KNOWLEDGE-BASE.md) for details, embeddings
options, and troubleshooting.
