Views, columns and marks

Views

Columns

Drag a header edge to resize; double-click it to reset.

Date
When the register row was last updated.
ATS
The applicant-tracking system the application went through.
Status
Where the application currently stands (list below).
Follow-up flag
A reply or follow-up is needed (e.g. answer an interview email, complete an assessment). Tick the box under Filters to show only those; set or clear the flag in the row's drawer or from the right-click menu.
Application states
The collapsible graph above the grid is the pipeline: each state shows how many live roles are in it, and clicking a state filters the grid to that status (Clear filters resets). CLOSED can follow any state.
Sorting
Click a column header to sort the whole list (the grid switches to a flat view); click again to reverse. Grouped in the toolbar returns to the bucket sections.
Right-click a row
Opens the row menu: open details/documents/the ad, prepare, submit prepared, recompute match, draft a reply, add to a group (campaign) or create one, manage groups from the Groups button, set status, close the role (status CLOSED), flag a follow-up, pin to the top, re-queue, hand to you, or copy the company/role/link/key. = pinned.
Level
Seniority grade read from the role title (then the ad): Intern, Junior, Mid, Senior, Staff, Principal, Lead, Manager, Director, VP, C-level. Click the header to sort, or use Level in Filters to narrow the grid.
Fit
How much of the ad's ATS keyword list the tailored CV covers. align✗ = the pre-submit alignment gate failed. Click to sort.
Pay
Estimated annual pay in EUR from the ad (hourly/day rates annualised at 1,600h/220d; approximate FX). Hover for the source text. - means no figure in the ad. Set one in the row's Summary. Click to sort.
Work
Remote / hybrid / on-site detected from the ad. Set an override in the row's Summary. Click to sort.
Queue
Where the role sits in the apply queue (list below).
Files (✓)
Provenance on file: the exact CV + letter and their SHA-256 hashes. - means none recorded.
Job ad (✓)
A saved job description exists for this role. - means none saved.
