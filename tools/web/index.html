Columns

Date
When the register row was last updated.

The applicant-tracking system the application went through.
Status
Where the application currently stands (list below).
⚑ action
A reply or follow-up is needed (e.g. answer an interview email, complete an assessment). Tick the box under Filters to show only those; set or clear the flag in the row's drawer.
Fit
How much of the ad's ATS keyword list the tailored CV covers. align✗ = the pre-submit alignment gate failed. Click to sort.
Pay
Estimated annual pay in EUR from the ad (hourly/day rates annualised at 1,600h/220d; approximate FX). Hover for the source text. — = no figure in the ad — set one in the row's Summary. Click to sort.
Work
Remote / hybrid / on-site detected from the ad. Set an override in the row's Summary. Click to sort.
Queue
Where the role sits in the apply queue (list below).
Files (✓)
Provenance on file — the exact CV + letter and their SHA-256 hashes. — = none recorded.
Job ad (✓)
